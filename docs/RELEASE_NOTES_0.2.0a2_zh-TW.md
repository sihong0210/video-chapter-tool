# 直播影片摘要工具 0.2.0 Alpha 2

發布通道：介面驗收預覽；尚未封裝

## 本輪修正

- 首頁可選取工作階段並開啟輸出、重新匯出或刪除。
- 刪除分為「只刪除 SQLite 記錄」與「記錄及該工作階段本機檔案」。
- 刪除本機檔案只接受已驗證的工作階段匯出子資料夾、PendingAudio、診斷報告與說話者分析暫存檔。
- TXT、JSON、SRT 全部寫入並驗證成功後才保存匯出路徑。
- 錄製流程在匯出成功後才標記完成；失敗時保留 SQLite 並顯示可重新匯出狀態。
- 已標記完成但缺少匯出檔的工作階段會顯示「需重新匯出」。
- UI 更新為深夜藍灰與冰藍強調色，統一導覽、卡片、表格、按鈕、焦點與危險操作樣式。
- 新增「音訊波形＋章節標記」應用程式圖示。

## 本輪驗收流程

1. 先以開發版檢視所有頁面的排版與配色。
2. 測試缺少匯出檔的工作階段能重新匯出。
3. 建立短錄製，分別驗證只刪記錄及連同檔案刪除。
4. 檢查 100%、125%、150% Windows 顯示縮放。
5. 使用者確認介面後才建立 `0.2.0a2` Portable EXE 與 ZIP。
