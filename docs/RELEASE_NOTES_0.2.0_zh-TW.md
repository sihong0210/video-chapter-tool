# 直播影片摘要工具 0.2.0

發布通道：Portable 正式版

## 主要功能

- 擷取 Windows 預設播放裝置的系統音訊並進行長時間串流轉錄。
- 使用 faster-whisper 產生臺灣繁體中文逐字稿及 TXT、JSON、SRT。
- 使用 SQLite 保存工作階段，支援強制關閉後復原待處理音訊。
- 使用本機 pyannote 模型標註 A／B 或自動判斷多人說話者。
- 將逐字稿與時間戳傳送到 OpenAI，產生章節導覽與完整摘要；不傳送音訊。
- 提供模型下載、診斷、重新匯出、安全刪除工作階段及資料路徑設定介面。
- Portable `UserData` 位於程式旁；模型與匯出資料夾可另行指定。

## 0.2.0 定版修正

- TXT、JSON、SRT 全部寫入並驗證成功後才將工作階段標記為完成。
- 已完成但缺少匯出檔的工作階段會顯示「需重新匯出」。
- 刪除工作階段可選擇保留輸出，或刪除經驗證屬於該工作階段的本機檔案。
- 完成深夜藍灰、冰藍強調色的正式介面與應用程式圖示。
- 修正模型選單只列出已下載可用的 Whisper 模型。
- 加入輪替日誌與不含逐字稿、音訊、SQLite、憑證的安全診斷包。

## 驗證

- 120 項自動化測試通過。
- 30 分鐘、1 小時與 3 小時 NVIDIA CUDA 串流穩定性 Gate 通過。
- Portable Alpha 2 已完成介面、錄製、匯出與工作階段管理實機驗收。
- 正式封裝會再次驗證中文路徑、EXE 旁 `UserData`、主要執行元件、NVIDIA 執行環境與 CPU fallback。

## 已知限制

- 尚未提供單一視窗音訊來源、AMD GPU 加速、說話者自訂名稱、自動更新或程式碼簽章。
- A／B 分析在開頭短句、重疊說話或音訊不清晰時可能暫時混淆。
- 模型不包含於 ZIP，第一次使用時需下載。
